<p>Manage Docker and Podman containers on your hosts over SSH, with logs, stats and a console</p>

</div>

<br />

## Overview

Docker manages the containers running on your hosts over SSH. It is not meant to replace Portainer or Dockge, just to handle the containers you already have.

Read the [docs](https://docs.termix.site/plugins/docker) to set it up and use it.

<br />

## Features

- Start, stop, restart, pause and remove containers
- Live CPU, memory, network and disk stats
- Read and download container logs
- Open a shell inside a container
- Works with Docker and Podman

## Support

Found a bug or have an idea for Docker? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Docker/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Docker/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
